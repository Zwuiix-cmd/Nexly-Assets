# Nexly Assets

Official resource and behavior pack assets for the **Nexly** framework on PocketMine-MP.

## About
This repository contains the textures, models, and client definitions required to support custom blocks and items powered by [Nexly](https://github.com/Zwuiix-cmd/Nexly).

## Usage
Clone or download this pack and configure it on your PocketMine-MP server to automatically load custom content for your players.
